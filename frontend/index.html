Hướng dẫn sử dụng khung Frontend cho nhóm

Khung dùng chung giúp các bạn sinh viên trong nhóm không bị xung đột code và thống nhất giao diện:

1. CSS & Giao diện

Mọi biến màu, nút bấm, form, bảng, badge Kanban và popup toast đã được đóng gói sẵn trong css/style.css. Không cần cài thêm thư viện CSS nặng.

2. Gọi API chung

Dùng api.get(), api.post(), api.put(), api.patch(), api.delete() trong js/api.js. Tự động gắn Bearer Token và dịch lỗi sang tiếng Việt.

3. Thêm trang mới

Tạo file pages/ten-trang.html với thẻ <body data-root="../">, thêm liên kết vào MENU trong js/layout.js. Header/footer sẽ tự động xuất hiện.
